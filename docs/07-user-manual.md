# 사용자 매뉴얼

'낭독 부스'는 적은 문장을 AI 목소리로 읽어 주는 화면입니다. 내 목소리를 녹음해 등록하면 그 목소리로 읽고, 문장 뒤에 붙는 잡음은 자동으로 잘라 냅니다. '진진가' 게임 진행 기능도 들어 있습니다.

## 1. 시작하기

### 1.1 설치 (처음 한 번)

Python 3.11이 설치된 Mac(Apple Silicon 권장)에서 저장소 폴더로 이동해 실행합니다.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 1.2 켜고 끄기

```bash
source .venv/bin/activate
python web/serve.py
```

- 터미널에 `낭독 부스: http://127.0.0.1:8780/  (끄려면 Ctrl+C)`가 나오면 Chrome이나 Safari에서 그 주소를 엽니다.
- **끄기**: 서버를 켠 터미널에서 **Ctrl+C**를 누릅니다. "꺼졌어요."가 나오면 끝입니다.
- 포트를 바꾸려면 `PORT=8790 python web/serve.py`처럼 실행합니다.
- 처음 목소리로 읽을 때 음성 모델(수 GB)을 내려받습니다. 인터넷 연결이 필요합니다.

> Claude 데스크톱 앱에 음성 서버를 등록해 두었다면, 앱 안에서 낭독 부스를 열어 같은 기능을 쓸 수도 있습니다. 이때는 웹서버를 켤 필요가 없습니다.

## 2. 화면 구성

| 영역 | 하는 일 |
|---|---|
| **진진가** (맨 위) | 게임 항목 카드, 질문 입력, 추천 질문, 지난 질문 |
| **대본** | 읽을 문장을 적는 곳. 자동 읽기 켬/끔 버튼, 글자 수와 예상 시간 |
| **예시** | 누르면 예시 문장이 대본에 들어감 |
| **음성 톤** | 기본, 여성, 사투리, 내 목소리 |
| **읽기 / 정지** | 재생 조작. 오른쪽에 소리 파형 |
| **녹음 목소리** | 사투리 톤에 쓸 목소리 연결 (내 Mac 복제 / Typecast) |
| **목소리** | 브라우저 음성 선택, 말하기 속도, 목소리 높이, 자연스러운 억양 |
| **최근 테이크** | 읽었던 대본 목록. 다시 듣기 |

## 3. 대본 읽기

1. **대본**에 문장을 적거나 **예시**를 누릅니다.
2. **음성 톤**을 고릅니다.

| 톤 | 목소리 | 특징 |
|---|---|---|
| 기본 | 브라우저 내장 음성 | 바로 읽음. 문장마다 억양과 쉼을 자연스럽게 바꿈 |
| 여성 | 브라우저 내장 여성 음성 | 조금 느리고 차분하게 |
| 사투리 | 녹음 목소리 패널에서 연결한 목소리 | 대본을 전라도 말투로 바꿔 읽음. 연결하지 않으면 브라우저 음성으로 흉내 |
| 내 목소리 | 등록한 녹음으로 복제한 목소리 | 대본 그대로 읽음. 새 문장은 10초 안팎 걸림 |

3. **읽기**를 누릅니다. 읽는 문장이 강조되고, 문장을 누르면 그 문장부터 다시 읽습니다.

**단축키**: ⌘(또는 Ctrl) + Enter 읽기, Esc 정지

**속도와 높이**: **목소리** 패널의 슬라이더로 조절합니다. 복제 목소리는 속도만 바뀌고 높이는 고정입니다.

## 4. 내 목소리 등록하고 쓰기

### 4.1 등록

1. 음성 톤에서 **내 목소리**를 고릅니다. 아래에 상자가 열립니다.
2. **내 목소리 새로 등록하기**를 펼칩니다.
3. **목소리 이름**을 적습니다(예: 지수).
4. 둘 중 하나로 녹음을 넣습니다.
   - **녹음 시작**을 누르고, 화면의 예시 문장을 평소 말투로 또박또박 읽은 뒤 **녹음 멈추기**를 누릅니다. 처음에는 브라우저가 마이크 허용을 묻습니다. 30초가 되면 자동으로 멈춥니다.
   - 또는 **녹음 파일 올리기**로 휴대폰이나 음성 메모 앱의 녹음(m4a, mp3, wav)을 올립니다.
5. 나타난 플레이어로 미리 들어 보고 **이 녹음으로 등록하기**를 누릅니다.

**잘 닮게 녹음하는 요령**
- 조용한 방에서 10~20초 녹음합니다. 5초보다 짧거나 30초보다 길면 등록되지 않습니다.
- 노트북 내장 마이크가 블루투스 이어폰 마이크보다 훨씬 잘 닮습니다. 이어폰 마이크는 통화 음질(16kHz)이라 먹먹한 목소리가 됩니다.
- 음악, TV, 에어컨 소리를 끕니다.

### 4.2 쓰기

- **읽을 목소리** 목록에서 목소리를 고르고 **읽기**를 누릅니다. 고른 목소리는 기억됩니다.
- 첫 문장은 모델을 불러오느라 30초~1분 걸릴 수 있습니다. 그다음부터 새 문장은 10초 안팎, 한 번 읽은 문장은 바로 나옵니다.

### 4.3 지우기

- 목록에서 지울 목소리를 고르고 **이 목소리 지우기**를 누릅니다. 문구가 "정말 지울까요?"로 바뀌면 4초 안에 **한 번 더** 누릅니다.
- 녹음 파일과 그 목소리로 만든 문장이 함께 지워집니다. 기본 목소리는 지울 수 없습니다.

> 녹음은 이 컴퓨터의 `src/refs/custom/`에만 저장됩니다. 다른 사람의 목소리는 본인 동의를 받고 등록하세요.

## 5. 사투리 톤

1. **녹음 목소리** 패널에서 목소리를 만드는 곳을 고릅니다.
   - **내 Mac에서 복제**: 무료. `src/voices.json`에 등록한 참조 녹음으로 복제합니다.
   - **Typecast**: `.env`에 `TYPECAST_API_KEY`가 필요하고, 새 문장마다 글자 수만큼 크레딧을 씁니다.
2. **연결하기**를 누르고 목소리와 감정을 고릅니다.
3. 음성 톤에서 **사투리**를 고르고 읽습니다. 음성 톤 아래에 바뀐 말투가 몇 곳인지 나옵니다.

## 6. 진진가 게임 진행

진진가는 발표자에 대한 다섯 항목 중 거짓 두 개를 찾는 게임입니다. 공개 저장소의 다섯 항목은 가상의 예시 인물입니다. 실제로 쓸 때는 `web/nangdok-booth.html`의 `ITEMS`를 본인 항목으로 바꿉니다.

**기본 흐름**
1. **항목 소개 읽기**로 다섯 항목을 읽어 줍니다.
2. 참가자 질문을 **질문** 칸에 넣고 **답변 듣기**(또는 Enter)를 누릅니다.
3. 답이 대본에 들어가고, **자동 읽기**가 켜져 있으면 바로 읽습니다.

**질문 입력 형식**

| 입력 | 읽는 내용 |
|---|---|
| `고양이 이름이 뭐예요?` | "고양이 이름이 뭐예요? 보리랑 콩이예요." |
| `지수: 고양이 이름이 뭐예요?` | "**지수님 질문,** 고양이 이름이 뭐예요? …" |
| `2번: 사진 있어요?` | "**2번 질문,** 사진 있어요? …" (2번 항목으로 답함) |

**버튼**
- **질문 먼저 읽기 켬/끔**: 답 앞에 질문을 읽을지 정합니다. 질문이 몰릴 때 어느 질문의 답인지 알기 쉽습니다. 끄면 대본에 답만 들어갑니다.
- **자동 읽기 켬/끔**: 끄면 답을 대본에 넣기만 하고, **읽기**는 직접 누릅니다. 답을 고쳐 읽고 싶을 때 씁니다.
- 항목 카드를 누르면, 항목이 애매한 질문을 그 항목으로 봅니다.
- **지난 질문**: 질문과 답 기록입니다. ▶를 누르면 다시 읽고, **목록 비우기**로 지웁니다.

**답은 어디서 오나요**
1. 증거를 보여 달라는 질문 → 정해진 거절 문구
2. 준비된 예상 질문과 비슷한 질문 → 준비된 답
3. 그 밖의 질문 → Claude가 항목 설정에 맞게 즉석으로 답함
   - 웹사이트에서는 `.env`에 `ANTHROPIC_API_KEY`가 있어야 합니다. Claude 앱 안에서는 키가 필요 없습니다.
4. Claude를 쓸 수 없으면 → 항목별 기본 답변 (상태 문구에 이유가 나옴)

## 7. 온라인 행사(ZEP 등)에서 쓰기

참가자 모두에게 AI 목소리를 들려주려면, 낭독 부스 소리를 화상회의 프로그램의 **마이크**로 보내야 합니다. 화면 공유는 소리를 보내지 않는 경우가 많습니다.

1. Loopback(유료, 체험판 있음) 또는 BlackHole(무료) 같은 가상 오디오 장치를 설치합니다.
2. 가상 장치의 소스에 **낭독 부스를 연 브라우저(또는 Claude 앱)**와, 진행자도 말하려면 **내장 마이크**를 넣습니다.
3. 화상회의 프로그램의 **마이크**를 그 가상 장치로, **스피커**를 내 이어폰으로 고릅니다.
4. 진행자는 **이어폰**으로 들어야 마이크가 낭독 소리를 다시 주워 메아리가 생기지 않습니다. 이어폰 마이크는 음질이 떨어지니 쓰지 않습니다.
5. 다른 기기로 참가자 계정에 들어가 소리가 잘 들리는지 미리 확인합니다.

## 8. 명령줄 도구

화면 없이 파이프라인만 쓸 때입니다.

```bash
# 한 문장을 내 목소리로 만들고 꼬리 잡음 자르기
python src/clean_tts.py --ref refs/my_voice.wav --text "좋아요, 다음 질문 받을게요!" --out out.wav --keep-stages

# 평가 20문장 다시 만들기, 듣고 판정하기
python eval/run_eval.py --ref refs/my_voice.wav
python eval/listen_server.py      # http://127.0.0.1:8770/
```

## 9. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 주소가 열리지 않음 | 서버를 켠 터미널이 열려 있는지, 주소가 `127.0.0.1:8780`인지 확인. 다른 프로그램이 포트를 쓰면 `PORT=8790`으로 켜기 |
| "음성 엔진을 시작하지 못했어요" | `src/worker.log`의 마지막 오류 확인. 패키지 설치와 메모리 여유 확인 |
| 내 목소리로 읽을 때 오래 걸림 | 첫 문장은 모델을 불러와서 늦음. 5분 동안 안 쓰면 모델을 내려서 다음 첫 문장이 다시 늦음 |
| 녹음 시작을 눌러도 녹음이 안 됨 | 브라우저 마이크 허용 확인. 안 되면 음성 메모로 녹음해 **파일 올리기** |
| 등록이 안 됨 | 녹음이 5~30초인지, 이름을 적었는지 확인 |
| 복제 목소리가 안 닮음 | 조용한 곳에서 내장 마이크로 10~20초 다시 녹음 |
| 즉석 질문에 기본 답변만 나옴 | 웹사이트: `.env`에 `ANTHROPIC_API_KEY`가 있는지 확인 후 페이지 새로고침 |
| 사투리 톤이 브라우저 음성으로 읽음 | **녹음 목소리** 패널에서 연결하고 목소리를 골랐는지 확인 |
| 문장 끝에 잡음이 남음 | 대본 끝을 음성인식이 못 알아들으면 일부러 자르지 않음. 문장을 짧게 나누면 나아짐 |
