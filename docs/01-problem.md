# 문제 정의서: AI 낭독 음성의 꼬리 잡음 자동 제거

> 측정 결과는 [03-evaluation.md](03-evaluation.md)에 있습니다.

## 1. 도메인

**온라인 행사·교육용 음성 콘텐츠 제작.** 정해진 대본이나 즉석 질문에 대한 답을 특정 인물의 목소리(예: 전라도 사투리 캐릭터)로 읽어 주는 일입니다.

- 실제로 사용한 곳: ZEP 온라인 모임에서 진행한 '진진가(진짜·진짜·가짜)' 게임. 참가자가 채팅으로 질문하면 AI가 답을 만들고, 그 답을 사투리 목소리로 읽어 참가자 전체에게 들려줍니다.
- 쓰는 도구: 텍스트 음성 변환(TTS)과 음성 복제(voice cloning). 상용 서비스(Typecast)와 로컬 오픈소스 모델(Chatterbox Multilingual)을 함께 썼습니다.

## 2. 현재의 문제

로컬 음성 복제 모델(Chatterbox)은 무료이고 원하는 목소리를 흉내 낼 수 있지만, **문장을 다 읽은 뒤에도 소리를 계속 만들어 내는 경우가 있습니다.**

- 마지막 단어 뒤에 웃음소리("흐흐흐"), 숨소리, 대본에 없는 말("안녕!")이 붙습니다.
- 음악이나 잡음 같은 소리가 터지는데, 목소리보다 크게 나올 때도 있습니다.
- 듣는 사람에게는 문장 사이에 **배경 소리나 다른 사람 목소리가 섞인 것**처럼 들립니다.

지금 이를 해결하는 방법과 불편한 점:

| 지금 하는 방법 | 불편한 점 |
|---|---|
| 생성된 음성을 사람이 하나씩 들어 보고 오디오 편집기에서 꼬리를 잘라냄 | 문장마다 듣고, 자를 위치를 찾고, 다시 저장해야 함. 평가에서는 20문장 중 15문장(75%)이 편집 대상이었음 |
| 잡음이 나온 문장을 다시 생성 | 생성이 문장당 약 10초 걸리고, 다시 만들어도 또 나올 수 있음 |
| 유료 TTS(Typecast)만 사용 | 문장마다 크레딧이 들고, 즉석 답변이 많은 게임에서는 비용이 쌓임 |

특히 진진가처럼 **즉석에서 만든 답을 바로 읽어야 하는 상황**에서는 사람이 듣고 편집할 시간이 없습니다.

## 3. 개선 가설

**음성 생성 직후에 AI 후처리 두 단계를 자동으로 붙이면, 사람이 편집하지 않아도 꼬리 잡음이 거의 없는 음성을 얻을 수 있다.**

```
대본 ─▶ ① Chatterbox: 목소리 복제로 음성 생성
          ─▶ ② Demucs: 음원 분리로 '목소리' 성분만 남김 (음악·잡음 제거)
          ─▶ ③ faster-whisper: 음성인식으로 대본의 마지막 단어가 끝나는 시점을 찾음
          ─▶ ④ 그 뒤 첫 쉼(160ms 무음)에서 자르고 짧게 페이드아웃
          ─▶ 깨끗한 음성 파일
```

- ②는 음악·잡음처럼 **목소리가 아닌 꼬리**를 없앱니다.
- ③④는 웃음·숨소리·엉뚱한 말처럼 **목소리이긴 하지만 대본에 없는 꼬리**를 없앱니다. 사투리는 음성인식이 조금 다르게 알아듣기 때문에(예: '죽겄네'를 '주건데'로 인식), 글자 대신 자모 단위로 대본과 맞춰 봅니다.
- 대본 끝을 제대로 알아듣지 못한 경우에는 자르지 않고 원본을 남깁니다. 말이 잘리는 것보다 꼬리가 남는 편이 덜 나쁘기 때문입니다.

## 4. 대상 사용자

- **1차: 나 자신.** 온라인 모임에서 AI 목소리로 게임을 진행하는 진행자.
- 2차: 오디오북·안내 방송·교육 영상처럼 로컬 TTS로 많은 문장을 만들어야 하는 개인 제작자. 유료 TTS 비용을 줄이고 싶지만 편집할 시간은 없는 사람.

## 5. 성공 기준

평가 문장 20개(표준어 10개, 사투리 10개)를 같은 설정으로 생성하고, 후처리 전후를 비교합니다.

| 지표 | 성공 기준 | 측정 방법 |
|---|---|---|
| 꼬리 잡음이 있는 문장 비율 | 후처리 후 **10% 이하** (기존 75%) | 사람이 직접 들어 보고 판정 |
| 단어가 잘려 나간 문장 수 | **20개 중 1개 이하** | 사람이 들어 보고, 음성인식 결과와 대본 비교 |
| 문장당 정리 시간 | 수작업 편집 대비 **5배 이상 단축** | 수작업은 스톱워치, 자동은 처리 시간 로그 |
| 실사용 | 20분짜리 게임 1회를 사람 편집 없이 진행 | 진행 기록 |

## 6. 범위 밖

- 음성 복제 품질 자체(목소리가 얼마나 닮았는지)는 개선 대상이 아닙니다.
- 문장 중간에 섞이는 잡음은 이번 범위가 아닙니다. 꼬리만 다룹니다.
- 실시간 스트리밍은 다루지 않습니다. 문장 단위로 처리합니다.
